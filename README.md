# 🎓 B1.2 - منصة تعلم قواعد الألمانية التفاعلية

منصة تعليمية متكاملة لتعلم قواعد اللغة الألمانية بمستوى B1، تشمل 16 مشروعاً تفاعلياً مع تتبع التقدم والوضع الليلي. تم تطويرها بواسطة **أبو نزار**.

## 📚 المحتويات
- شرح القواعد: Nebensätze, Passiv, Konjunktiv II, Adjektivdeklination وغيرها.
- اختبارات تفاعلية مع نطق صوتي.
- شريط تقدم لحفظ إنجازات المستخدم (localStorage).
- دعم الوضع الليلي.

## 🚀 كيفية الاستخدام
1. قم بفتح ملف `index.html` في أي متصفح حديث.
2. ادرس المشاريع بالترتيب المقترح (8 أسابيع).
3. اضغط على زر "📘 ادرس الآن" لبدء المشروع.
4. عند إتمامك مشروعاً، اضغط "✅ مكتمل" ليتقدم شريط الإنجاز.

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3 (Flexbox, Grid, متجاوب)
- JavaScript (ES6)
- التخزين المحلي (localStorage)
